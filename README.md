# Current

A cross-platform client for browsing, requesting and playing media from [Jellyfin](https://jellyfin.org),
[Seerr](https://github.com/seerr-team/seerr) (Overseerr/Jellyseerr) and [Stash](https://github.com/stashapp/stash).
A shared Kotlin core with a native SwiftUI app on Apple platforms (iOS, macOS, tvOS later), Compose Multiplatform on Android and Windows,
and a React + TypeScript web app (ADR 0011; the web shell is still the Compose placeholder until M1 replaces it).
Every service is optional: the app works with whichever of them you run.

> Status: project skeleton (generated by kmp.jetbrains.com, plus module tree, docs and CI). No features yet; see [docs/roadmap.md](docs/roadmap.md).

## Requirements
- JDK 21 (any JDK 17+ works for Gradle)
- Android Studio or IntelliJ IDEA with the Kotlin Multiplatform plugin
- Android SDK (API 37) for Android
- A Mac with Xcode 26 for the Apple apps (open `iosApp/iosApp.xcodeproj`)
- A browser with WasmGC for web

## Run
```
.\gradlew.bat :desktopApp:run                          # desktop (use ./gradlew on macOS/Linux)
.\gradlew.bat :webApp:wasmJsBrowserDevelopmentRun      # web
.\gradlew.bat :androidApp:installDebug                 # Android
```
