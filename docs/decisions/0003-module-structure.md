# 0003: Wizard shells plus layered modules

Status: accepted

## Decision
Keep the shells generated by kmp.jetbrains.com (`androidApp`, `desktopApp`, `webApp`, `iosApp`) and add layered KMP modules: `core/*`, `data/*`,
`feature/*`, `composeUi`, plus the `apple` umbrella (ADR 0006). Dependencies point down only; features never import each other.
Each module's build file copies the shape of an existing one (hand-written convention plugins failed against AGP 9; revisit `build-logic` only if duplication hurts).
Pure-Kotlin modules target android, iOS, macOS arm64, tvOS, jvm, wasmJs. Compose modules target android, jvm, wasmJs.
(ADR 0011: the web becomes React + TypeScript over Kotlin/JS, so pure-Kotlin modules gain `js` and the web drops Compose.)
Modules are created empty and filled when real code arrives.

Only `core:designsystem` exposes Material 3 (`api`) to the Compose side.
